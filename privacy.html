개인정보처리방침

세이브 워치 앱은 기도 기록과 메모를 서버로 보내지 않아요. 만든 사람을 포함해 누구에게도 보내지 않아요.

기기에 저장하는 것

이 기기, 이 브라우저의 localStorage에 다음 값을 저장해요.

savewatch_v1
기도 기록을 저장해요. 기록 식별자, 기도한 사람, 시작 시각, 잰 시간(초), 메모와 손으로 더한 기록인지 표시하는 값이 들어가요.
savewatch_run_v1
진행 중인 기도의 시작 시각과 시작 밀리초를 저장해요.
savewatch_notice_v1
백업 안내를 닫았는지 저장해요.
savewatch_mode_v1
기도 중 시간 표시 방식을 저장해요.
savewatch_v1.corrupt.<시각>
손상된 기록의 원문을 따로 보관해요. 같은 이름이 있으면 뒤에 번호가 붙을 수 있어요.
savewatch_probe
저장할 수 있는지 확인하려고 잠깐 썼다가 바로 지워요.

Cache Storage에는 앱 화면 파일만 보관해요. 기도 기록과 메모를 넣지 않아요.

보내지 않는 것

기도 기록과 메모를 서버로 전송하지 않아요. 앱에 분석·광고·로그인 기능이 없고, 앱이 쿠키를 읽거나 설정하지 않아요.

인터넷을 쓰는 때

앱 화면 파일을 GitHub Pages에서 받거나 갱신할 때 인터넷을 써요. 서비스워커, 설치 정보, 아이콘, 안내 페이지도 화면 파일에 포함돼요. 화면 파일이 기기에 보관된 뒤에는 인터넷이 없어도 앱을 열 수 있어요. 브라우저가 보관한 파일을 지우면 다시 연결해야 할 수 있어요.

이때 IP 주소와 요청한 페이지 주소 같은 접속 정보가 호스팅 회사 GitHub에 전달돼요. GitHub가 이 정보를 어떻게 처리하는지는 아래 GitHub 방침을 따라요.

GitHub 개인정보처리방침

백업 파일

기록 내보내기는 기록과 보관한 손상 원문을 내 기기에 파일로 내려받아요. 이 파일은 암호화되지 않아요. 파일을 어디에 둘지는 쓰는 사람이 정해요. 진행 중인 기도와 표시 방식은 백업에 따로 넣지 않아요. 가져오기는 고른 파일을 기기에서 읽으며, 서버로 업로드하지 않아요.

파일을 남에게 주면 그 사람이 기록과 메모를 볼 수 있어요.

기록을 지우는 법

지난 기록 › → 고치기 → 이 기록 지우기로 한 건씩 지울 수 있어요. 오래 진행된 기도를 정리하는 화면의 지우기는 그 진행 상태를 지워요.

브라우저의 사이트 데이터 삭제로 저장된 기록과 설정, 보관한 화면 파일을 지울 수 있어요. 내려받은 백업 파일은 파일을 보관한 곳에서 따로 지워 주세요.
