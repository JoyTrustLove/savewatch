# SAVE WATCH (세이브 워치)

**기도한 시간이 쌓이는 시계.**
멈추면 사라지는 스톱워치가 아니라, 통장 잔고처럼 남고 쌓이는 시계입니다.

👉 **[바로 열기](https://joytrustlove.github.io/savewatch/)**

---

## 어떤 도구인가

폰 기본 스톱워치로 기도 시간을 재면, 정지하는 순간 숫자가 사라집니다.
남는 게 없으니 잴 이유가 없고, 그래서 결국 안 재게 됩니다.

SAVE WATCH는 그 고리를 끊습니다. **잰 시간이 반드시 남고, 계속 쌓입니다.**

```
   지금까지 쌓인 기도
      12시간 40분        ← 화면의 주인공. 줄어들지 않습니다
      오늘 · 25분

     [    시 작    ]      ← 버튼은 하나뿐
```

## 쓰는 법

1. 위 링크를 **폰 브라우저**로 엽니다
2. 공유 버튼 → **홈 화면에 추가**
3. 아이콘이 생깁니다. 이제 앱처럼 열립니다

설치도, 회원가입도 필요 없습니다.

> ⚠️ **지금은 앱을 여는 순간에 인터넷이 필요합니다.** 기록 자체는 폰 안에 있어 인터넷과 무관하지만, 화면을 불러오는 데는 연결이 필요합니다. 비행기 모드에서도 열리게 하는 작업은 다음 판에 넣습니다.

## 기록은 어디에 있나

**이 기기 안에만 있습니다. 어디로도 보내지 않습니다.**
서버가 없고, 계정도 없고, 수집하는 것도 없습니다.

다만 그래서 브라우저 저장소를 비우면 기록도 함께 사라집니다.
`지난 기록 → 기록 내보내기`로 가끔 파일로 간직해 두세요. 같은 파일을 `가져오기`하면 그대로 돌아옵니다.

## 만들 때 지킨 것

- **일곱 살도, 일흔 살도** — 설명 없이 큰 버튼 하나로 시작합니다
- **줄지 않습니다** — 하루 빠져도 어제 쌓은 것은 그대로입니다.
  연속 기록(streak)·랭킹·독촉 알림은 **일부러 넣지 않았습니다.** 기도는 채점하는 것이 아니니까요
- **넣으면 눈금이 움직입니다** — 40초를 쌓았는데 "0분"이라고 하지 않습니다
- **색이 없어도 읽힙니다** — 색으로만 구분하는 표시를 쓰지 않았습니다
- **잰 것은 잃지 않습니다** — 저장에 실패하면 성공한 척하지 않고 사실대로 알립니다

## 만듦새

파일 **하나**입니다. `index.html` 안에 화면·동작·아이콘이 전부 들어 있습니다.
프레임워크도, 빌드 도구도, 외부 요청도 없습니다.

내려받아 더블클릭해도 그대로 열립니다.
